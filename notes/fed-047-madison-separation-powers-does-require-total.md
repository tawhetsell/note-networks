Separation of powers does not require total separation — only that no single branch controls another entirely. Montesquieu's maxim, properly read, allows blending. Britain's constitution — Montesquieu's own model — blends the branches substantially. Some interpenetration is necessary for each branch to check the others; absolute separation would leave each powerless against encroachment.
